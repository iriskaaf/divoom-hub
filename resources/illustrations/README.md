# Card artwork

- `spotify.svg`: unmodified green icon from Spotify's official icon archive:
  https://developer.spotify.com/images/guidelines/design/2024-spotify-logo-icon.zip
  (`Primary_Logo_Green_RGB.svg`). Spotify is a trademark of Spotify AB.
  Usage guidelines: https://developer.spotify.com/documentation/design
- `media-session.svg`: Divoom Hub's monitor/play illustration for Windows media sessions.
- Device photos are supplied by the project owner in `imgs/ditoo.png` and
  `imgs/times-gate.png`. The original transparent images are bundled unchanged.

All artwork is loaded locally; no download is needed when using the application.
