# Как устроен Divoom Hub

## Интерфейс и устройства

`winui/App.xaml.cs` проверяет, не запущен ли уже экземпляр приложения, и создаёт `MainWindow`.

`MainWindow.xaml` содержит заголовок, боковую навигацию, место текущей страницы и мастер первого запуска. `Pages/` собирает страницы из стандартных WinUI-контролов. `Controls/Form.cs` задаёт общие карточки, строки настроек, переключатели и кнопки. `PageSurface` отвечает за заголовок, прокрутку и сообщения.

`HubProfile` хранит источник музыки и список `DeviceEntry`. У каждого устройства свои ID, имя, адрес и настройки. Навигация использует ID, поэтому два Times Gate не смешивают состояния. `DeviceLive` содержит временное состояние: онлайн, статус и кадры; оно не записывается в пользовательский профиль.

Сохранение идёт через временный файл с последующей заменой JSON. LocalToken хранится отдельно в Windows Credential Manager. Частые изменения слайдера объединяются таймером на 350 мс.

## Связь с Python

`Services/PythonBackend.cs` запускает дочерний процесс без консоли и передаёт команды строками JSON через stdin/stdout. Каждая команда получает числовой ID. Ответ с тем же ID завершает соответствующий Task. События устройства дополнительно содержат его ID.

`MainWindow.Backend.cs` переводит события в состояние интерфейса. Запись конфигурации сериализована: новый запрос ждёт завершения предыдущего. При остановке бэкенда устройства отмечаются как отключённые.

`Backend/worker.py` содержит `Fleet`: один музыкальный движок и обработчик на каждое устройство. Модули обработки находятся в `legacy/core`, `legacy/bluetooth` и `legacy/timesgate`. PySide6 не загружается в WinUI-бэкенде.

## Медиасессия → средний экран Times Gate

1. `core/media_session.py` читает Windows SMTC: название трека, исполнителя, воспроизведение и thumbnail.
2. `core/player.py` обновляет текущий трек и обложку. При изменении отправляется событие `track`.
3. `Fleet.event()` обновляет интерфейс и будит каждый Times Gate.
4. `timesgate/engine.py` получает обложку через общий cover provider. Если музыка играет и включён `tg_center_cover`, третий кадр заменяется обложкой.
5. `timesgate/digits.py` рисует остальные экраны. `timesgate/client.py` отправляет кадры на конкретный IP с LocalToken.
6. На паузе движок восстанавливает двоеточие или выбранный режим. WinUI получает кадры отдельной командой `preview`.

Обложка для интерфейса декодируется заново только при изменении её данных. Предпросмотры обновляются при изменении состояния, настроек и минуты; в скрытом главном окне запросы предпросмотра не выполняются.

## Трей и диалоги

WinForms используется только для регистрации NotifyIcon в системном трее. Само меню — WinUI `MenuFlyout`, с нативными иконками, подменю и навигацией клавиатурой. Скрытый служебный якорь позволяет открыть меню, когда главное окно свёрнуто; после закрытия меню он скрывается.

Выбор цвета — `ContentDialog` внутри текущего XamlRoot. Пока диалог открыт, редактируется временный цвет. «Готово» применяет его, «Отмена» оставляет настройки прежними. Переходы между страницами используют `EntranceThemeTransition`.

## Проверки

`legacy/tests` проверяет протокол, обработку обложек, рендер, настройки и прежний GUI. `winui/Diagnostics/UiSmokeTest.cs` проверяет реальные WinUI-контролы. `Backend/smoke_test.py` поднимает локальный HTTP-сервер вместо часов и проверяет несколько независимых устройств. Эти проверки не заменяют испытаний реальной Bluetooth-связи и светодиодов.
