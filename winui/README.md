# Divoom Hub · WinUI 3

Это Divoom Hub с интерфейсом на C# и WinUI 3 и обработчиками музыки и устройств на Python. Python запускается в отдельном процессе без окна вместе с приложением.

## Запуск

Готовая сборка находится в `artifacts/DivoomHub.WinUI`. Запускай `divoom-hub-winui3.exe`. При переносе копируй всю папку. Python и .NET входят в сборку.

В Visual Studio открой `divoom-hub-winui3.slnx`, выбери **x64**, профиль **Unpackaged** и нажми F5. При запуске из исходников приложение ищет соседнюю папку `legacy` и его `.venv`. Другой путь можно указать переменной `DIVOOM_HUB_PYTHON_ROOT`.

```powershell
.\Build.ps1
```

Профиль записывается в `%LOCALAPPDATA%\DivoomHub.WinUI\ui-settings.json`. LocalToken и авторизация Spotify хранятся в диспетчере учётных данных Windows. Крестик скрывает окно. Команда «Выход» в трее останавливает Python и возвращает встроенный циферблат Times Gate, если это включено.

В `artifacts/test` находится отдельный `divoom-hub-winui3_TEST.exe`. При каждом новом запуске он открывает приветственный экран и подставляет настройки из старого Python-профиля, если этот профиль найден. Тестовая версия использует `%LOCALAPPDATA%\DivoomHub.WinUI_TEST` и отдельную авторизацию Spotify. Чтобы подключать реальные устройства из TEST, сначала выйди из других сборок через трей.

В основной версии можно добавить сколько нужно Times Gate и Ditoo Pro. В разделе «Устройства» отдельная квадратная плитка открывает мастер добавления, а плитка конкретного устройства открывает подключение, переименование и удаление.

### От нажатия до результата

Пункты устройств создаются в `MainWindow.RefreshDeviceMenu()`. В `Tag` находится ID конкретного устройства. Событие `SelectionChanged` вызывает `NavigationChanged`, а `Navigate()` передаёт в `PageHost.Content` соответствующую страницу.

Рассмот́ри переключатель «Обложка вместо двоеточия» в `GatePages.cs`.

```csharp
var centerCover = Form.Toggle(
    "Обложка вместо двоеточия", p.TgCenterCover,
    value => { p.TgCenterCover = value; window.Save(); });
```

Первый аргумент задаёт подпись, второй задаёт начальное состояние. Третий аргумент передаёт функцию, которую `Form.Toggle` вызывает при событии `Toggled`. Она меняет свойство объекта `HubProfile`. `Save()` записывает профиль в JSON, а `SyncAsync()` передаёт настройки Python.

В режиме «Картинки по бокам, часы в центре» `Render()` скрывает этот переключатель и показывает выбор боковых файлов. Значение переключателя хранится в профиле, так что при возврате к пяти экранам выбор остаётся прежним.

### Граница с Python

C# и Python обмениваются строками JSON через стандартные потоки дочернего процесса. Команда `configure_all` передаёт общий источник музыки и массив устройств. Поле `id` в ответе связывает его с запросом. Поле `device` в событии указывает, какой карточке и точке онлайн соответствует новый статус.

У `Fleet` в Python один обработчик музыки. Каждому Times Gate соответствует собственный рендер и HTTP-клиент. Каждому Ditoo соответствует свой Bluetooth-поток, которому общий обработчик передаёт трек и обложку. Цвет, яркость и режим экрана одного устройства сохраняются независимо от остальных.

`core/player.py` читает медиасессию и сохраняет трек с картинкой. `worker.py` получает событие `track` и будит обработчики Times Gate. Каждый из них выбирает обложку для третьего экрана, готовит JPEG 128×128 и отправляет его через `timesgate/client.py`. На паузе часы возвращают двоеточие. WinUI отдельно запрашивает `preview` для конкретного устройства и `thumbnails` для галереи.

Проверка сборки запускается с `--ui-smoke-test <абсолютный-путь-к-отчёту>`. Она открывает тестовый интерфейс, проверяет ZIP и связь с Python, используя профиль в памяти. `Backend/smoke_test.py` проверяет упакованный Python на локальном имитаторе Times Gate.

Графика устройств взята из `imgs` прежнего проекта. Значок Spotify из [официального набора Spotify](https://developer.spotify.com/documentation/design#using-our-logo).
